# PCB

KiCad 10 project for the Starbie Stocks board (a car-shaped 2-layer PCB,
about 100 x 65.5 mm).

- `stonkstarbie.kicad_pro`, `.kicad_sch`, `.kicad_pcb`: the project, schematic and board.
- `gerbers/`: Gerber and drill files exported from KiCad, ready to send to a PCB fab.
  Suggested options: 2 layers, 1.6 mm, blue solder mask, white silkscreen.

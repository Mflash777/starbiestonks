# PCB

Put your KiCad project here (`.kicad_pro`, `.kicad_sch`, `.kicad_pcb`) along
with any custom symbol and footprint libraries from the Week 1 Care Package.

Also add a `Gerbers/` folder (or a `Gerbers.zip`) exported from KiCad via
**File > Fabrication Outputs > Gerbers**, plus the drill files.
